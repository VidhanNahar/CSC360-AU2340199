## Questions 

### 1. Computer Graphics vs. Digital Image Processing
* **Computer Graphics (CG)**: The process of synthesizing, manipulating, and rendering digital visual content from abstract mathematical descriptions, 2D/3D geometric models, or data structures.
  $$\text{Data / Models} \xrightarrow{\text{Synthesis / Rendering}} \text{Image}$$
* **Digital Image Processing (DIP)**: The process of applying mathematical operations to existing digital images to analyze, enhance, restore, segment, or extract feature data.
  $$\text{Image} \xrightarrow{\text{Processing / Analysis}} \text{Processed Image / Feature Data}$$

---

### 2. Geometric Primitives of Drawing
Geometric primitives are the fundamental vector objects used by graphics systems to build complex shapes and models:
* **Points**: 0D entities defined by coordinates specifying a precise position in space (e.g., $(x, y)$ in 2D or $(x, y, z)$ in 3D).
* **Lines / Line Segments**: 1D entities representing straight paths connecting two endpoint coordinates.
* **Polygons**: 2D closed planar shapes bounded by straight line segments (e.g., triangles, quadrilaterals; triangles are the primary rasterization primitive).
* **Curves / Circles / Ellipses**: Non-linear paths defined by parametric or implicit mathematical equations (e.g., Bézier curves, splines).

---

### 3. Graphical Frameworks in Java
Java provides multiple generations of graphical toolkits and rendering APIs:
* **AWT (Abstract Window Toolkit)**: The original Java GUI library using native operating system windowing components (*heavyweight*).
* **Swing**: Built on top of AWT, offering platform-independent, pluggable look-and-feel GUI components rendered entirely in Java (*lightweight*).
* **Java 2D API**: Extends AWT/Swing to provide advanced 2D vector rendering, stroke/fill styling, alpha compositing, and affine coordinate transformations.
* **JavaFX**: The modern successor to Swing, featuring a hardware-accelerated scene graph architecture, FXML for declarative UI design, and CSS styling.

### 4. Design Patterns for User Interfaces
UI architectures and design patterns separate concerns to make applications modular and maintainable:
* **Architectural Patterns**:
  * **MVC (Model-View-Controller)**: Separates application state (Model), display representation (View), and input handling (Controller).
  * **MVP (Model-View-Presenter)**: View is passive; the Presenter manages UI logic and updates the view via interfaces.
  * **MVVM (Model-View-ViewModel)**: Connects the View to the ViewModel using declarative two-way data binding.
* **Behavioral & Structural Patterns**:
  * **Observer**: Enables event-driven updates where views listen and react to state changes in models.
  * **Command**: Encapsulates user actions (e.g., button clicks, menu items) as objects to support queuing, logging, and undo/redo functionality.
  * **Composite**: Structures UI elements into tree hierarchies (containers containing nested widgets and layout panels).

### 5. Static vs. Interactive Graphics
* **Static Graphics**: Fixed visual media where the content is pre-rendered and does not respond to user interactions (e.g., JPEG/PNG images, vector exports, printed diagrams).
* **Interactive Graphics**: Dynamic rendering systems that listen for real-time user inputs (mouse movements, keyboard presses, gestures), update internal state, and continuously re-render frames (e.g., video games, GUI applications, CAD tools).

### 6. Curves and Calculus
Calculus provides the mathematical foundation for representing, evaluating, and rendering smooth curves:
* **Tangents and Derivatives ($C^1$ Continuity)**: The first derivative with respect to parameter $t$ ($\frac{d\mathbf{r}}{dt}$) gives the velocity/tangent vector indicating direction and speed along the curve.
* **Curvature ($C^2$ Continuity)**: The second derivative ($\frac{d^2\mathbf{r}}{dt^2}$) measures the rate of change of the tangent vector, determining curvature and sharpness of bends.
* **Arc Length**: Definite integration ($\int_{a}^{b} \|\mathbf{r}'(t)\| \, dt$) computes the precise geometric length along a curve.
* **Splines & Bézier Curves**: Mathematical continuity constraints ($C^0, C^1, C^2$ and $G^0, G^1, G^2$) ensure smooth blending between joined polynomial curve segments.

### 7. SSH vs. HTTPS for Git Repositories
| Feature | HTTPS (`https://`) | SSH (`git@github.com:...`) |
| :--- | :--- | :--- |
| **Port** | 443 (standard web SSL/TLS traffic) | 22 (SSH traffic) |
| **Authentication** | Personal Access Tokens (PAT) / OAuth | Asymmetric public/private key pairs |
| **Setup** | Immediate, works through firewalls | Requires generating and registering an SSH key |
| **Convenience** | May require credential helper | Passwordless once keys and ssh-agent are configured |

---

### 8. SSH Tools & Utilities
* **`ssh`**: The core command-line client used for secure shell connections and remote authentication.
* **`ssh-keygen`**: Utility used to generate cryptographic key pairs (e.g., `ssh-keygen -t ed25519`).
* **`ssh-agent`**: Background daemon that stores decrypted private keys in memory.
* **`ssh-add`**: Command-line tool to load private keys into `ssh-agent`.
* **Configuration File (`~/.ssh/config`)**: Per-user configuration file for managing host aliases, key associations, and ports.

---

### 9. Public and Private Keys in Asymmetric Cryptography
* **Public Key**: Shared openly (e.g., uploaded to GitHub). It is used to encrypt data destined for the key owner or to verify cryptographic signatures created by the corresponding private key.
* **Private Key**: Kept strictly secret on the local machine. It is used to decrypt data encrypted with the public key and to generate digital signatures proving identity during authentication.

## Key Takeaways
* Computer graphics synthesizes visual data from math/models, whereas image processing transforms and analyzes existing images.
* Asymmetric SSH key authentication provides a secure, passwordless workflow for interacting with Git repositories.
* Mastering Java's graphical pipeline (AWT $\rightarrow$ Swing $\rightarrow$ Java 2D $\rightarrow$ JavaFX) and geometric primitives forms the foundation for 2D/3D graphics programming.
