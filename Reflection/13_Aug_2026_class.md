## Reflection

* Introduction to graphical frameworks in Java (AWT, Swing, and Java 2D).
* Understanding the role of Maven for Java project lifecycle management (`pom.xml`, `exec-maven-plugin`).
* GUI rendering fundamentals: Extending `JPanel` and overriding `paintComponent(Graphics g)`.
* Drawing 2D geometric primitives using the `Graphics` context (`drawRect` to render an empty/hollow square).
* Managing window containers using `JFrame` to display custom graphics.
